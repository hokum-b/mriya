what is mriya

mriya is a scrolling x11 window manager written in c. windows are arranged on a horizontal ribbon-style strip. the user scrolls through this strip instead of stacking windows in columns. mriya is heavily inspired by niri and i3.

features

  • horizontal tiled strip that scrolls left and right.
  • up to ten workspaces.
  • window states of normal, floating, maximized, and fullscreen.
  • per-window titlebars with close and maximize buttons.
  • configurable colors, gaps, borders, and snapping.
  • keybindings, autostart commands, and layout settings in a plain text config.
  • hot reload of the config at runtime.
  • ewmh support for standard window managers.

window states

  • normal, tiled on the strip.
  • floating, free to move and resize with the mouse.
  • maximized, a single wide window on the strip.
  • fullscreen, covers the whole monitor.

controls

  • focus moves left or right along the strip.
  • scroll left and right when the strip is wider than the screen.
  • drag tiled windows to reorder them.
  • drag floating windows to move them.
  • resize windows with the mouse.
  • titlebar buttons close and maximize the focused window.

keybindings

  • default bindings use the super modifier, short mod.
  • mod plus shift plus return spawns a terminal.
  • mod plus d spawns dmenu.
  • mod plus h j k l move focus.
  • mod plus up and down switch workspaces.
  • mod plus shift plus j and k change gaps.
  • mod plus space zooms to the master window.
  • mod plus shift plus space toggles floating.
  • mod plus f toggles maximize.
  • mod plus shift plus f toggles fullscreen.
  • mod plus tab cycles views.
  • mod plus 1 through 9 views a workspace.
  • mod plus shift plus 1 through 9 tags the focused window.

config

config lives at $XDG_CONFIG_HOME/mriya/mriya.rc, else $HOME/.config/mriya/mriya.rc. a fallback lives at /etc/mriya/mriya.rc. on first run a default config is written if none exists.

directives use a key colon value format. colors are written as hex values like #222222. numbers are written as integers. a line starting with a hash is a comment.

settings

  • norm_bg sets the background color for unfocused windows.
  • sel_bg sets the background color for focused windows.
  • norm_outer_border sets the outer border color for unfocused windows.
  • sel_outer_border sets the outer border color for focused windows.
  • norm_inner_border sets the inner border color for unfocused windows.
  • sel_inner_border sets the inner border color for focused windows.
  • urgent_color sets the color of urgent windows.
  • title_active_bg sets the background of the focused titlebar.
  • title_active_fg sets the text color of the focused titlebar.
  • title_inactive_bg sets the background of unfocused titlebars.
  • title_inactive_fg sets the text color of unfocused titlebars.
  • inner_gap sets the gap between windows.
  • outer_gap sets the gap at the screen edges.
  • snap sets the snapping distance for window edges.
  • outer_border_width sets the outer border width.
  • inner_border_width sets the inner border width.
  • border_width sets both borders to one width.
  • total_border_width sets the full border width.
  • show_titlebar toggles titlebars, 1 on or 0 off.
  • show_title toggles the title text.
  • show_buttons toggles the titlebar buttons.
  • insert_end toggles whether new windows attach at the end.
  • strip_align sets strip alignment, 0 left, 1 right, else center.
  • show_move_indicator toggles the move indicator overlay.
  • move_indicator_color sets the move indicator color.
  • mod_key sets the mod key, super, alt, ctrl, or shift.

directives

  • autostart runs a command on startup.
  • bind runs an external command when a chord is pressed.
  • call runs a built-in action when a chord is pressed.
  • workspace maps a chord to a view or tag action.

chords use the mod word plus optional shift, ctrl, alt, super. the full syntax is key plus key plus key colon value.

examples

bind : mod + shift + return : alacritty

call : mod + space : zoom

workspace : mod + 1 : view 1
workspace : mod + shift + 1 : tag 1

built-in actions

  • close_window closes the focused window.
  • quit exits mriya.
  • restartwm restarts mriya.
  • reload_config reloads the config.
  • focusleft moves focus left.
  • focusright moves focus right.
  • ws_up goes to the previous workspace.
  • ws_down goes to the next workspace.
  • inc_gaps increases gaps.
  • dec_gaps decreases gaps.
  • zero_gaps resets gaps.
  • zoom moves the focused window to the master position.
  • togglefloating toggles floating state.
  • togglemaximize toggles maximized state.
  • togglefullscreen toggles fullscreen state.
  • view switches the visible workspace.
  • tag assigns the focused window to a workspace.

build

make builds the mriya binary. make install installs mriya to /usr/local/bin. mriya links against xlib. development packages needed are libx11-devel, libxkbfile-devel, and libxkbcommon-devel. alsamixer and brightnessctl are optional for volume and brightness keys.

run

startx mriya runs the window manager. for a display manager create /usr/share/xsessions/mriya.desktop. the desktop entry exec is mriya.

notes

  • mriya is tested on linux, freebsd, netbsd, and openindiana.
  • mriya is licensed under the 3 clause bsd license.
  • some distros do not put /usr/local/bin on the default path.
